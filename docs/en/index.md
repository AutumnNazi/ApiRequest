# ApiRequest Design Documentation

English | [简体中文](../index.md)

> A Postman-like API debugging and collaboration tool.
> Stack: Wails v2 (Go backend) + React + TypeScript (frontend). Goal: a full-featured release.

This directory contains the ApiRequest design documentation. See the repository-level [README.md](../../README.md) for the project introduction; this page is the navigation entry point for the design docs.

## Suggested Directory Structure

The complete directory structure has a single source of truth in [overview.md](./overview.md#suggested-directory-structure) and is not repeated here. In brief: the frontend lives in `frontend/`; the Go backend is split under `backend/` into `binding`, `httpengine`, `script`, `template`, `storage`, `platform`, `convert`, `protocol`, `mock`, and `model`; and `wailsjs/` is generated by Wails rather than edited by hand.
