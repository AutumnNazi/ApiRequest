# Glossary

English | [简体中文](../glossary.md)

> Back to the [Documentation Index](./index.md).

| Term | Meaning |
|------|---------|
| Workspace | Top-level container that isolates collections and environments |
| Collection | Root grouping node for requests |
| Environment | A switchable set of variables |
| Runner | Batch collection executor with data-driven runs |
| Cookie Jar | Local storage that manages cookies by domain and path |
| Node (in this design) | Unified tree entity for collections, folders, and requests |
| Example | Example response attached to a request; produced by "Save as Example" and used as Mock Server data |
| oplog | Operation log used for synchronization and conflict ordering |
| PKCE | Interception-resistant extension to the OAuth 2.0 Authorization Code flow |
| TTFB | Time To First Byte |
| mTLS | Mutual TLS, where the client also presents a certificate |
| IR | Intermediate Representation shared by import, export, and code generation |
| Adapter / Converter | Converts between an external format and the internal model |
